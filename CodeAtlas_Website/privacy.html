PLAIN-LANGUAGE PRIVACY NOTE

Your learning data stays in your browser.

This page describes the current local-first version of CodeAtlas. It is not legal advice or a substitute for a full privacy policy if new data services are added.

What is stored locally?

Depending on which tools you use, CodeAtlas may save your graduate profile, career assessment answers/results, lesson progress, bookmarks, study notes, and resume-builder content in your browser’s local storage. This helps the website remember your work on the same browser and device.

What this means

  • These local records are not automatically synced to another device.
  • Clearing browser site data can remove locally saved work. Export or copy important material when available.
  • Anyone with access to your unlocked browser profile may be able to view locally saved information.
  • A static site cannot securely hide a provider API secret; CodeAtlas does not ask you to paste API secrets into browser pages.

External links

Some pages link to external documentation, job boards and research resources. Those sites have their own privacy practices. Review the destination before submitting information.

AI and cloud services

Cloud account sync and live AI counselling are not active unless a separately configured service is deployed. Do not assume that a button or roadmap item means a service is already connected. If those features are added, this notice must be updated to explain data sent, purpose, retention, provider and user controls before launch.

Contact and data controls

The current static site does not provide a hosted contact form or cloud account deletion workflow. You can clear local site data using your browser settings, but that action removes saved progress and drafts from this device.
