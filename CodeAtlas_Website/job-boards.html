How the recent-job collector works

A GitHub Actions workflow checks configured public ATS endpoints approximately every six hours, normalizes source job IDs, records first-seen timestamps, expires older records, and writes a JSON feed that the Recent Jobs page reads. The starter board identifiers are not guaranteed to all be valid, so check the workflow logs and expand the list only after testing.

  • Greenhouse, Lever and Ashby public job-board endpoints where available
  • Scheduled runs using GitHub Actions, with secrets stored in repository settings
  • JSON storage for deduplication and first-seen dates in this starter version; move to a database if the feed grows substantially
  • Filters for role, location, keywords and recent discoveries
