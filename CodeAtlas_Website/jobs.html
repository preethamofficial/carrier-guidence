HOW IT WORKS

Fresh listings, with honest labels

  • GitHub Actions runs daily at 9:00 AM India Standard Time (03:30 UTC) and publishes changed feed data automatically after validation. GitHub may delay scheduled runs during high load.
  • Listings include available job descriptions, source dates and direct application links. Descriptions are converted to plain text and may be missing when the source board does not expose them. Duplicate roles are removed using the source board and external job ID; older retained records are periodically removed.
  • “First seen” means the collector discovered the role, not that the employer posted it on that date.
  • The starter company list is small and some board identifiers may need verification. No paid API key is required for the configured public endpoints.
